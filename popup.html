AI is getting ready

Chrome needs to download its local Gemini Nano model once. It is a few GB and normally happens in the background.

Chrome AI is not available here

On-device AI may be turned off in Chrome settings, or your Chrome version or hardware may not support Gemini Nano.

  1. Turn on On-device AI in chrome://settings/ai. Chrome Beta, Dev and Canary start with it off
  2. Use Chrome 138+ on a desktop computer
  3. Check for 16 GB RAM, 4 GB VRAM, and 22 GB free disk space
  4. On Chrome 127–137, enable Prompt API for Gemini Nano in chrome://flags
  5. Advanced: model status is in chrome://on-device-internals after you enable debug pages in chrome://chrome-urls
Edge on-device AI is not available here

Edge's on-device model is still a preview: it needs an edge://flags opt-in and supported hardware. Turn on Fast tone check in the cloud above with a SubQ or TypeSafe key, or set it up:

  1. In edge://flags, enable Prompt API for on-device language model and restart Edge
  2. Use Windows 10/11 or macOS 13.3+ with 5.5 GB VRAM, 20 GB free disk and an unmetered connection
  3. In edge://on-device-internals, Device performance class should be High or above
  4. If sessions fail, try Enable prerelease on-device language model in flags — the CPU model needs no GPU
  5. On a work device, your organization may have turned on-device AI off
Enable Firefox on-device AI

Comment Vibe can classify tone with Firefox’s local AI runtime. The small model downloads once and your comments stay on your device.

If you blocked AI features in Firefox Settings → AI controls (Firefox 148+), allow them again: blocking also switches off the AI API that add-ons use.

On Firefox 134–139, also set browser.ml.enable and extensions.ml.enabled to true in about:config (on by default since Firefox 140).
