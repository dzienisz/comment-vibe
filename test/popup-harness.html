Popup harness

Model state: downloadable · downloading · available · unavailable

Firefox popup: fraction · bytes · unknown shape · fails

Options: &start=0.4 (progress already done when reopened), &duration=6000 (ms for the rest of the download), &activation=required (create() needs a click, like Chrome may require), &fail=1 (download fails), &reattach=0.2 (first event after reopening is lower, like real Chrome).

Reload the page mid-download to simulate closing and reopening the popup.
